### beUI identity and integration verification

Official documentation: https://beui.dev and https://beui.dev/components/motion/button. Official source repository and license: https://github.com/starc007/ui-components and https://github.com/starc007/ui-components/blob/main/LICENSE.

The official site identifies React 19, Tailwind 4, and Motion requirements and documents installation through a shadcn registry or manual source copying. This project uses the **documented manual source-copy approach**, not a guessed npm package. Actual registry source and dependency declarations were inspected before integration. React 19, Tailwind 4, Motion, clsx, tailwind-merge, and Lucide are installed and locked. Native modal dialog is used for focus trapping/inert background; beUI buttons form its actions. Inputs have labels, field error IDs and aria-invalid in the actual library source. FAQ triggers have aria-expanded/aria-controls and closed content is inert. Reduced-motion handling exists in the library source and the app uses MotionConfig reducedMotion="user".

### Image-generation prompt

Built-in tool, `photorealistic-natural` / product still-life intent (submitted taxonomy: `product-mockup`), no reference images. Original output copied unchanged into the project:

> Use case: product-mockup. Asset type: hero image for a development and therapy center website. Create a beautiful photorealistic editorial still life of tactile wooden children's educational building blocks on a warm off-white tabletop. An architectural playful arrangement: large cobalt blue arch, green semi-circular arch, muted vermilion red cylinder, buttery yellow stepped blocks, natural maple rectangular pieces, a few small wooden spheres. Soft natural afternoon sunlight from the upper left, subtle realistic shadows, pale sage background, refined Montessori materials, calm optimistic mood. Close three-quarter perspective, balanced sculptural composition filling a square image, generous breathing room around arrangement. No people, no hands, no text, no logos, no watermark. Premium design magazine photography, organic wood texture. Image will be placed next to black typography, green buttons and authentic colorful logo.
